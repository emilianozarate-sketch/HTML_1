# 🌐 Fundamentos de HTML 📝

¡Bienvenido al repositorio de **Fundamentos de HTML**! 🚀 Aquí encontrarás todo lo necesario para dar tus primeros pasos en el desarrollo web y dominar la estructura básica del internet. 🕸️

---

## 🎯 Objetivo
Este proyecto está diseñado para aprender, repasar y practicar las etiquetas y conceptos esenciales de **HTML5**. Es el punto de partida perfecto para cualquier aspirante a desarrollador frontend. 🎓

---

## 📚 Contenido del Repositorio

En las diferentes carpetas de este proyecto exploraremos los siguientes temas:

*   🏗️ **Estructura Básica:** Plantilla inicial (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
*   ✍️ **Texto y Formato:** Títulos (`<h1>` a `<h6>`), párrafos (`<p>`), énfasis (`<strong>`, `<em>`).
*   🔗 **Enlaces (Links):** Creación de hipervínculos (`<a>`) internos y externos.
*   🖼️ **Multimedia:** Inserción de imágenes (`<img>`), audio (`<audio>`) y video (`<video>`).
*   📋 **Listas:** Listas ordenadas (`<ol>`) y desordenadas (`<ul>`).
*   📊 **Tablas:** Filas, columnas y encabezados (`<table>`, `<tr>`, `<td>`, `<th>`).
*   📝 **Formularios:** Cajas de texto, botones y selectores (`<form>`, `<input>`, `<button>`, `<select>`).
*   🧩 **HTML Semántico:** Buenas prácticas para estructurar tu web moderna (`<header>`, `<nav>`, `<main>`, `<footer>`, `<article>`, `<section>`).

1.  **Clona este repositorio** en tu máquina local copiando este comando en tu terminal:
